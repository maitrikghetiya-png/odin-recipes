# Odin Recipes 🍽️

A simple recipe website built as part of **The Odin Project – Foundations** course.

## 📖 About the Project

This project contains a homepage with links to three recipe pages. Each recipe page includes a description, ingredients, and cooking steps.

## 🍴 Recipes

- Pasta
- Pizza
- Sandwich

## 🛠️ Built With

- HTML5

## 📂 Project Structure

```text
odin-recipes/
├── index.html
└── recipes/
    ├── pasta.html
    ├── pizza.html
    └── sandwich.html
```

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone git@github.com:maitrikghetiya-png/odin-recipes.git
   ```

2. Open the project folder:

   ```bash
   cd odin-recipes
   ```

3. Open `index.html` in your browser.
